# چارچوب کار نوبتینو

راهنمای اجرایی تیم‌ها در [`_framework/README.md`](./_framework/README.md) است. برای تحویل طراحی هر صفحه از [الگوی تحویل](./_framework/page-handoff.md) استفاده کنید.

مرجع قواعد بصری [سیستم طراحی](../docs/design-system.md) و مرجع نام، شناسه و مسئولیت صفحه‌ها [فهرست صفحه‌ها](../docs/page-inventory.md) است. [AGENTS.md](../AGENTS.md) قواعد ثابت این پوشه را مشخص می‌کند.

این پوشه محل مستندسازی است. طراحی اختصاصی و نیازمندی هر صفحه در محل کار تیم مسئول آن ثبت می‌شود و پیاده‌سازی در محل کار تیم فرانت‌اند انجام می‌شود.
