# یادداشت‌های مرجع قالب

این پوشه یادداشت‌های عمومی قالب دربارهٔ کار با دستیارهای هوش مصنوعی را نگه می‌دارد. قواعد پروژه از [AGENTS.md](../../../AGENTS.md) و روند همکاری از [راهنمای تیم‌ها](../README.md) خوانده می‌شوند. هرجا یادداشتی از «چارچوب ما»، نقش‌ها، ارکستراسیون، مراحل اجرا یا ساختار پرونده‌ها صحبت می‌کند، منظور قالب عمومی است. این یادداشت‌ها جای مسئولیت تیم صفحه، نیازمندی مصوب یا سیستم طراحی را نمی‌گیرند.

برای نوشتن تحویل صفحه، [راهنمای نوشتن مشخصات](./spec-writing-for-agents.md) و [مدیریت زمینه](./context-management.md) منابع اختیاری‌اند؛ فرم مورد استفادهٔ همهٔ تیم‌ها [الگوی تحویل صفحه](../page-handoff.md) است.
