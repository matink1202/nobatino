# نوبتینو

این پوشه مرجع قالب‌بندی و استانداردهای بصری سایت فارسی نوبت‌دهی پزشکان است. خروجی اینجا مستندات طراحی است. طراحی اختصاصی، محتوای هر صفحه و جریان آن به تیم مسئول صفحه واگذار شده است. پیاده‌سازی در محل کار تیم فرانت‌اند و با HTML، CSS و JavaScript خالص انجام می‌شود.

- [سیستم طراحی](./docs/design-system.md): رنگ، تایپوگرافی، فاصله‌گذاری، ظاهر اجزا و قواعد دسترس‌پذیری.
- [فهرست هفت صفحه](./docs/page-inventory.md): نام و شناسهٔ مشترک صفحه‌ها و محل ثبت تیم مسئول.
- [چارچوب همکاری تیم‌ها](./llm-work-template-main/_framework/README.md): مرز مسئولیت، مسیر تحویل و بازبینی.
- [دستورالعمل مشترک پروژه](./AGENTS.md): قواعد ثابت برای تیم‌ها و دستیارها.
